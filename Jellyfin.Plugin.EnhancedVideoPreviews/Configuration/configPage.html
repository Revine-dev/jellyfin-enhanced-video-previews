Enhanced Video Previews

GitHub

Configures smooth hover video previews for movies, TV series, and episodes across the Jellyfin Web interface.

Toggle video preview playback on or off globally.
When enabled, the plugin automatically adds the client script to Jellyfin's web assets. If your container filesystem is read-only, see the manual injection instructions below.
Time in seconds where the video preview will start (e.g., 840 = 14 minutes in). If media is shorter than this duration, it automatically starts at 15% into the video to avoid intro sequences.
Milliseconds of mouse hover before preview begins playing (recommended: 100 - 200 ms).
Playback rate used during video previews.
Resolution width used when transcoding is required.
Attempts direct stream playback without server transcoding first.
Falls back to server transcoding if direct streaming cannot be played by the browser.
When checked, previews always stay silent. When unchecked, previews start muted (required for autoplay) and unmute automatically once playback begins; a small mute/unmute button also appears on the preview so viewers can override it manually.
Repeats preview video seamlessly while hovered.
